# Color Palette Extractor

A Python-based utility for extracting dominant color palettes from visual assets using unsupervised machine learning.

## Project Overview
This project processes image files, converts color spaces, and applies K-Means clustering to identify dominant chromatic values. It bridges computational data processing with visual aesthetics, generating structured color breakdowns.

## Tech Stack
* **Language:** Python 3.10+
* **Libraries:** OpenCV, NumPy, Scikit-learn, Matplotlib
